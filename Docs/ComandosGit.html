Lista geral de Comandos Git

Comando O que faz
git status Mostra arquivos modificados, novos, deletados e pendentes de commit.
git add . Adiciona todas as alterações para o próximo commit.
git add nome-arquivo Adiciona apenas um arquivo específico para o próximo commit.
git commit -m "mensagem" Cria um commit com as alterações adicionadas.
git push Envia os commits locais para o repositório remoto.
git pull Baixa e aplica alterações do repositório remoto.
git clone URL Copia um repositório remoto para sua máquina.
git log --oneline Mostra o histórico resumido de commits.
git log --oneline -5 Mostra os últimos 5 commits.
git diff Mostra as alterações feitas antes de adicionar ao commit.
git diff --staged Mostra alterações já adicionadas com git add.
git branch Lista as branches locais.
git branch nome-branch Cria uma nova branch.
git checkout nome-branch Troca para outra branch.
git checkout -b nome-branch Cria e já entra em uma nova branch.
git switch nome-branch Troca para outra branch usando comando moderno.
git switch -c nome-branch Cria e entra em uma nova branch usando comando moderno.
git merge nome-branch Mescla outra branch na branch atual.
git remote -v Mostra os repositórios remotos configurados.
git remote add origin URL Adiciona o repositório remoto chamado origin.
git push -u origin main Envia a branch main e define o remoto padrão.
git restore nome-arquivo Desfaz alterações locais de um arquivo ainda não commitado.
git restore --staged nome-arquivo Remove arquivo da área de stage, mas mantém as alterações no arquivo.
git reset --soft HEAD~1 Desfaz o último commit, mantendo as alterações prontas para novo commit.
git reset --hard HEAD~1 Desfaz o último commit e apaga as alterações. Use com cuidado.
git stash Guarda temporariamente alterações sem commit.
git stash list Lista alterações guardadas no stash.
git stash pop Restaura a última alteração guardada no stash.
git tag Lista tags de versão do projeto.
git tag v1.6.0 Cria uma tag local de versão.
git push origin v1.6.0 Envia uma tag de versão para o repositório remoto.
git fetch Baixa informações do remoto sem aplicar no código local.
git clean -fd Remove arquivos e pastas não rastreados. Use com cuidado.
