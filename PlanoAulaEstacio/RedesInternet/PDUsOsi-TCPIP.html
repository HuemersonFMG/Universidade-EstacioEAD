PDUs das Camadas OSI e Equivalência com o Modelo TCP/IP

Durante a comunicação em uma rede, os dados recebem diferentes nomes conforme passam pelas camadas dos modelos de referência. Esses nomes são chamados de PDUs — Protocol Data Units, ou Unidades de Dados de Protocolo. A tabela abaixo apresenta as sete camadas do modelo OSI, o PDU utilizado em cada camada e sua equivalência com o modelo TCP/IP.

O que é um PDU?

PDU é o nome dado à unidade de informação processada em cada camada de um modelo de rede. Embora o conteúdo original continue sendo o dado produzido pela aplicação, cada camada adiciona informações de controle, chamadas de cabeçalhos e, em alguns casos, trailers.

Importante: nas camadas de Aplicação, Apresentação e Sessão, o PDU é normalmente chamado apenas de dados. Na camada de Transporte, o nome depende do protocolo: utiliza-se segmento para TCP e datagrama para UDP.
