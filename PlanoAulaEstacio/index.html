Resumo rápido

6 meses - Objetivo: API + Integração ERP

Objetivo: ficar apto a construir APIs em Node.js/TypeScript, integrar com ERPs (SOAP/REST), trabalhar com Oracle/Postgres e fazer deploy com PM2/Docker.

Checklist inicial

  • JS moderno & TypeScript — dominar async/await e tipos.
  • Git avançado + GitHub (PRs, branching).
  • HTTP, REST, JSON, Postman/Insomnia.
  • Node.js + Express (ou Fastify) com testes.
  • SQL (Oracle/Postgres) e ORM (TypeORM/Knex).
  • Consumir SOAP (node-soap) e REST (axios) — mapeamento XML↔JSON.
  • Deploy: PM2, Docker, CI/CD (GitHub Actions).
  • Observability: logs, health checks, monitoramento básico.

Stack recomendado

  • Linguagens: JavaScript + TypeScript.
  • Framework: Node.js + Express / Fastify.
  • Bancos: Oracle (integração ERP) e Postgres; Redis para filas/cache.
  • Infra: PM2, Docker, VPS (DigitalOcean/Hetzner/AWS) e Cloudflare (tunnel/DNS).
  • Integração: node-soap, axios, xml2js.

Projetos para portfólio

3 projetos
  • API CRUD (Node+TypeScript) com OpenAPI e testes automatizados.
  • Adaptador ERP: consome SOAP, mapeia e persiste em Postgres/Oracle.
  • Gateway com fila (Redis), retries e deploy com PM2/Docker.

Certificações rápidas

Sugestões: Node.js bootcamp, Oracle SQL (básico-avançado), AWS Cloud Practitioner.

Entrega final

3 projetos no GitHub, README completo e vídeo demo de 2–3 minutos.

Exemplos

Exemplo: rota Express + validação simples

// app.ts (trecho)
import express from 'express';
import cors from 'cors';
import helmet from 'helmet';
const app = express();
app.use(cors());
app.use(helmet());
app.use(express.json());
app.post('/clientes', async (req, res) => {
const { nome, documento } = req.body;
if (!nome || !documento) return res.status(400).json({ error: 'dados faltando' });
// gravar em DB / enviar ao ERP
return res.status(201).json({ ok: true });
});

Análise da disciplina DGT0284 (Redes) — tópicos completos

Foco prático

Lista completa de tópicos (DGT0284 - Fundamentos de Redes) — adaptada para uso prático em backend/integração ERP:

  • Modelos de referência: OSI (7 camadas) e TCP/IP — função de cada camada e impacto em aplicações.
  • Topologias de rede: ponto-a-ponto, barramento, estrela, malha, híbrida.
  • Meios físicos e transmissão: par trançado, cabo coaxial, fibra óptica, wireless (básico).
  • Endereçamento IP: IPv4 (classes, subnetting, máscara), IPv6 (conceitos básicos).
  • Subnetting e VLSM — divisão de redes e cálculo de sub-redes.
  • Protocolos de transporte: TCP (handshake, controle de fluxo, retransmissão) e UDP (características e usos).
  • Protocolos de rede: IP, ICMP, ARP — funções e diagnóstico (ping, traceroute).
  • Roteamento: conceitos, tabelas de roteamento, roteadores vs switches, roteamento estático e dinâmico (conceito).
  • NAT e PAT — tradução de endereços e implicações para serviços expostos (port forwarding).
  • DNS: resolução de nomes, tipos de registros (A, AAAA, CNAME, MX, TXT), TTL e troubleshooting.
  • Segurança de redes: firewalls (filtragem por portas/IP), listas de controle (ACL), conceitos de DMZ.
  • Criptografia em redes: SSL/TLS (handshake, certificados), HTTPS e boas práticas para APIs.
  • VPNs e túneis: conceitos de VPN (IPSec, SSL VPN), Cloudflare Tunnel e uso para expor serviços com segurança.
  • Serviços de rede: DHCP, NTP, Syslog e seu papel em servidores de aplicação.
  • Balanceamento e alta disponibilidade: load balancers, health checks, failover e replicação simples.
  • Ferramentas de diagnóstico: Wireshark, tcpdump, netcat, nmap, curl, telnet, ss/netstat.
  • Monitoração e logs: métricas básicas, alertas, e como configurar health endpoints em APIs.
  • Conceitos de VLANs e segmentação de rede (básico) para separar ambientes (produção/teste).
  • Considerações sobre performance de rede: latência, throughput, MTU, e impacto em integrações SOAP/REST.
  • Boas práticas para deploy: segurança de portas, políticas de backup, atualizações e hardening do servidor.

Observação: esta lista foi adaptada para priorizar itens relevantes a deploy e integrações ERP.
